## 各テストの詳細

### 1. ユニットテスト: `getLoanBadge`（貸出ステータスのバッジ判定）

**対象**: `app/admin/page.tsx` 内の `getLoanBadge` 関数

> 自販機でいうと「お金を入れたら金額がカウントされる」レベル。
> 1つの関数に1つの入力を渡して、正しい出力が返るかだけを見る。

| テストケース | 入力 | 期待する出力 |
|---|---|---|
| 貸出中のデータ | `returnedProcessed: false` | `label: "貸出中"`, `bg: "#dbeafe"`（青） |
| 返却済みのデータ | `returnedProcessed: true` | `label: "返却済み"`, `bg: "#f3f4f6"`（グレー） |

- **外部依存**: なし（Firestore不要、DOM不要）
- **実行速度**: 数ミリ秒

---

### 2. 結合テスト: `addLoan`（貸出作成 + 在庫連携）

**対象**: `lib/firestore.ts` 内の `addLoan` 関数

> 自販機でいうと「お金を入れて商品ボタンを押すと、
> 金額が足りていれば商品が出る。足りなければエラー」レベル。
> 複数の処理（getDoc → 在庫チェック → writeBatch）が連携して正しく動くかを見る。

| テストケース | 条件 | 期待する動作 |
|---|---|---|
| 在庫あり（3冊） | 書籍が存在し stock=3 | 貸出レコード作成 + 在庫 3→2 + バッチコミット |
| 書籍が存在しない | getDoc で exists=false | エラー「書籍が見つかりません」、バッチ未コミット |
| 在庫0 | 書籍が存在し stock=0 | エラー「在庫がありません」、バッチ未コミット |

- **外部依存**: Firebase Firestore をモック（jest.mock）で差し替え
- **検証ポイント**: 関数の呼び出し順序・引数・エラーハンドリング

---

### 3. E2Eテスト: ユーザー業務フロー（ログイン〜各画面操作〜ログアウト）

**対象**: アプリ全体

> 自販機でいうと「お客さんが来て→お金入れて→商品選んで→
> おつり受け取って帰る」の全行程。
> 実際のブラウザ（Chromium）で、ユーザーが体験する一連の流れを再現する。

| ステップ | 操作 | 確認内容 |
|---|---|---|
| 1 | `/login` にアクセス | ログインフォームが表示される |
| 2 | メール・パスワードを入力してログイン | 書籍管理ページに遷移する |
| 3 | サイドバーで「ダッシュボード」に移動 | 統計カード（総書籍数・利用者数）、最近の貸出、人気ランキングが表示 |
| 4 | サイドバーで「書籍管理」に移動 | フォームに入力可能、書籍一覧テーブルが表示 |
| 5 | サイドバーで「貸出管理」に移動 | 貸出申請フォーム、貸出一覧テーブルが表示 |
| 6 | 「ログアウト」をクリック | ログイン画面に戻る |

- **外部依存**: 実際の Firebase Auth / Firestore（テスト用アカウント必要）
- **CI実行時**: GitHub Secrets に `E2E_EMAIL` / `E2E_PASSWORD` を設定

## 今後追加を検討するテスト

### ユニットテスト

| テスト対象 | 内容 |
|---|---|
| フォームバリデーション（書籍登録） | タイトル空→不可、価格が負→エラー、在庫に小数→エラー |
| フォームバリデーション（貸出登録） | 利用者名空→不可、書籍未選択→不可 |
| カテゴリのデフォルト値処理 | 未指定/空文字 → 「その他」 |

### 結合テスト

| テスト対象 | 内容 |
|---|---|
| `updateLoan` + 在庫調整 | 書籍変更時に旧+1・新-1、同じ本なら在庫変動なし |
| `returnLoan` + 在庫更新 | 返却で在庫+1、二重返却で在庫変動なし |
| `deleteLoan` + 在庫戻し | 貸出中の削除で在庫+1、返却済みの削除では変動なし |

### E2Eテスト

| テスト対象 | 内容 |
|---|---|
| 書籍の登録→貸出→返却の一連フロー | 在庫の増減が画面上で正しく反映される |
| 書籍情報の編集フロー | フォームに既存値が入り、更新後に一覧に反映 |
| 認証ガード | 未ログインで `/admin/*` → `/login` にリダイレクト |
